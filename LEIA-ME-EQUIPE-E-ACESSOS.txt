TURBO LANCHES - EQUIPE E ACESSOS - ATIVACAO PELO LOVABLE

Este projeto esta no Lovable e voce nao precisa ter acesso ao painel do Supabase.
Nao use Supabase CLI, token, senha do banco ou login do Supabase.

ORDEM CORRETA:

1. Execute:
   1 - ENVIAR PARA GITHUB E LOVABLE - CORRIGIDO.bat

2. Aguarde o projeto sincronizar no Lovable.

3. Execute:
   2 - ATIVAR EQUIPE PELO LOVABLE.bat

4. O navegador sera aberto e o comando sera copiado automaticamente.
   Abra o projeto Turbo Lanches, pressione CTRL + V no chat e envie.

5. Aguarde o Lovable confirmar:
   - migration aplicada
   - Edge Function admin-manage-staff publicada
   - teste realizado

6. Clique em Publish/Update no Lovable.

Depois disso, no painel, abra "Equipe e acessos" para cadastrar:
- Administradores
- Vendedores
- Caixas
- Permissoes individuais por secao

No menu do perfil, a conta principal podera alternar entre:
- Administracao
- Vendedor
- Caixa
- Cliente

A troca de visao nao encerra a sessao.
